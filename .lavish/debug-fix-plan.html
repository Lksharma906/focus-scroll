  • Reset Bug: FeedManager.setPlaylist resets currentIndex = 0. Adding video #4 instantly reloads video #1! The user never sees their newly added Short load.
  • Dead Drawer: The drawer list shows the newly added item at the bottom, but clicking it does not play it (Issue 3).
  • Duplicate Lockout: When the confused user clicks "Add" a second time, storage.addItem throws "This video is already in your list".
  • Regex Fragility: URL regex /(?:https?:\/\/)?(?:www\.)?youtube\.com\/shorts\/([a-zA-Z0-9_-]{11})/ fails on URLs from mobile browsers with subdomains like m.youtube.com or trailing query params like ?feature=share or ?si=... if formatted differently.
2 Why scrolling to next is not working

// src/gestures/engine.ts - Line 30

this.element.addEventListener('touchstart', this.handleTouchStart, { passive: false });

this.element.addEventListener('touchmove', this.handleTouchMove, { passive: false });

this.element.addEventListener('touchend', this.handleTouchEnd, { passive: false });

// NO pointerdown, NO mouse drag, NO wheel, NO keydown!

  • Touch-Only Listeners: On any desktop browser (Mac, Windows, Chrome, Safari), standard mouse clicks and drags emit mouse/pointer events, NOT TouchEvent.
  • Wheel / Trackpad Ignored: 2-finger trackpad swipes or mouse wheel ticks emit WheelEvent, which is never intercepted or processed.
  • Keyboard Navigation Missing: Standard shortcuts (↓, ↑, Space, J, K) have no handlers.

Behavior Comparison: Current vs Target

Feature / Scenario Current Behavior Target Behavior
Adding New Short Link Resets player to index 0. User sees video #1 replay. Drawer stays open; user thinks addition failed. Second attempt triggers "already in list" error. Immediately selects and jumps to the newly added video, loads title automatically via oEmbed fallback, closes the drawer (or shows an active checkmark), and plays unmuted.
Desktop / Trackpad Navigation 100% non-functional. Mouse drag does nothing. Trackpad 2-finger swipe does nothing. Arrow keys do nothing. Unified gesture engine supporting PointerEvents (mouse & touch drag), debounced wheel / trackpad scroll, keyboard shortcuts (↑/↓/Space), and HUD desktop next/prev buttons.
Selecting Video from Drawer Unclickable. User is trapped on whichever video is currently active with no way to pick another one. Clicking any item immediately jumps to that video index, closes drawer, persists active index, and displays a success toast.
URL Flexibility Strict regex fails on certain mobile URLs (m.youtube.com), URLs with query strings, or trailing slashes. Universal parser extracts standard 11-char ID from any YouTube URL variation (Shorts, watch, share links, embeds, mobile, raw IDs).
