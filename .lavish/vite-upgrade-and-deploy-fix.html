🔍 Root Cause Breakdown

1. Server Deploy Failure Cloudflare CI/CD 
✘ [ERROR] The version of Vite used in the project ("5.4.21") cannot be automatically configured.
Please update the Vite version to at least "6.0.0" and try again.

In non-interactive CI, Wrangler v4 detected Vite but found no configuration file (wrangler.jsonc). It defaulted to running its new automatic framework configuration adapter, which requires Vite ≥ 6.0.0 and prompt interactivity.

2. Local Build Failure npm run build (tsc) 
error TS2322: Type 'Mock<Procedure | Constructable>' is not assignable to type '(items: VideoEntry[], ...) => void'
tests/unit/drawer-scroll-multilist.test.ts:26

When you updated Vite and Vitest to modern versions, Vitest changed its unparameterized vi.fn() mock return signature. Because tsconfig.json includes "tests", tsc aborted the build.

🛠️ Changes & Fixes Applied

1 Created wrangler.jsonc for Cloudflare Workers Static Assets

Provides explicit configuration for Cloudflare Workers Assets. This stops Wrangler from prompting or attempting automated Vite framework re-scaffolding during CI/CD. 

{
  "$schema": "node_modules/wrangler/config-schema.json",
  "name": "focus-scroll",
  "compatibility_date": "2026-09-03",
  "assets": {
    "directory": "./dist",
    "not_found_handling": "single-page-application"
  }
}
2 Fixed Mock Types in tests/unit/drawer-scroll-multilist.test.ts

Specified explicit generic types on Vitest Mock<...> so TypeScript strict checking passes without warnings: 

import { describe, it, expect, beforeEach, vi, type Mock } from 'vitest';
import { VideoEntry } from '../../src/types/storage';

let onPlaylistUpdatedMock: Mock<(items: VideoEntry[], targetIndex?: number) => void>;
let onSelectVideoMock: Mock<(index: number) => void>;
let onToastMock: Mock<(msg: string) => void>;
3 Updated package.json to Fully Compatible Modern Versions

Aligned vite-plugin-pwa to ^1.3.0 to eliminate Rolldown bundle assignment warnings in Vite:
