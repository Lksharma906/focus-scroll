FocusScroll Hosting, PWA & Persistence Blueprint

The non-expert guide to zero-cost hosting, permanent phone-memory persistence, iPhone/Android PWA installation & privacy protection.

100% Free Tier Local Phone Memory Private By Default
💾 Does it persist over sessions in phone memory?

YES, completely! FocusScroll is built on IndexedDB backed by LocalStorage. Your lists live directly in your physical device's flash memory.

When you install it as a PWA ("Add to Home Screen"), iOS and Android allocate dedicated, isolated origin storage that persists across phone reboots, app updates, and browser session restarts.

✓ We also enabled navigator.storage.persist() to prevent OS cache eviction!
🔒 What if I post it on Twitter? Can others see or touch my list?

NO ONE can see or edit your lists! There is NO central database on the web.

Every person clicking your link on Twitter gets an isolated, empty sandbox running on their own phone/computer. They have zero access to your device memory or your curated playlists.

✓ Optional: You can also lock the URL with Cloudflare Access (Email OTP) if you want 0 public visitors!
PART 1

The Easiest Hosting Options: Choose Your Path

Both are 100% free forever, provide free HTTPS, and support instant PWA installation.

⚡ Cloudflare Pages

RECOMMENDED

The easiest, fastest hosting in the world. Free unlimited bandwidth, lightning-fast edge CDN, free .pages.dev domain, and built-in privacy protection.

1 Method 1: Direct 30-Second Terminal Deploy (No Git Required) 
npm run build
npx wrangler pages deploy dist --project-name=focus-scroll

It will ask you to authorize Cloudflare in your browser once, upload your dist folder, and give you an instant live URL like https://focus-scroll.pages.dev!

OR
2 Method 2: Connect GitHub Repository (Auto-Deploy on Git Push)
  1. Push your code to a GitHub repository.
  2. Log in to Cloudflare Dashboard > Workers & Pages > Create Application > Pages.
  3. Select your GitHub repo.
  4. Set Build command to npm run build and Output directory to dist.
  5. Click Save and Deploy. Done! Every time you push code, Cloudflare builds and updates your app automatically.

🐙 GitHub Pages

BUILT-IN

Great if your code is already hosted on GitHub and you want everything in one single place.

1 Install the gh-pages helper 
npm install --save-dev gh-pages
2 Deploy in 1 Command 
npm run build && npx gh-pages -d dist

We already set base: './' in vite.config.ts, so it will work cleanly without any 404 asset path errors on https://<username>.github.io/<repo>/!

PART 2

Locking the App: "I Want it Only for Myself"

How to flaunt it on Twitter without strangers using your deployment.

🛡️ Level 1: Client Isolation (Already Active!)

Even if 1,000,000 people on Twitter open your website, they CANNOT see your videos or alter your playlists. All playlists exist solely in the local browser IndexedDB of the device viewing it. A visitor on Twitter will see an empty onboarding screen.

🔑 Level 2: Cloudflare Zero Trust (100% Free Private Lock)

If you don't even want strangers to be able to open the app:

  1. In Cloudflare dashboard, click Zero Trust > Access > Applications.
  2. Add an application for your domain (e.g. focus-scroll.pages.dev).
  3. Add a policy: Allow only my email address (yourname@gmail.com).
  4. Now, whenever anyone visits the URL, Cloudflare asks for a 6-digit one-time passcode sent only to your email. You can install it on your phone, log in once, and nobody else can enter!
PART 3

Installing as a Native PWA on iPhone & Android

How to get the fullscreen, borderless, app-store style app on your home screen.

🍎 iPhone (iOS Safari)

1
Open in Safari

You MUST open your hosted URL in Safari (iOS Apple restriction: Chrome on iOS cannot install PWAs).

2
Tap the Share Icon

Tap the square icon with an upward arrow at the bottom center of Safari.

3
Tap "Add to Home Screen"

Scroll down the share sheet and select "Add to Home Screen" (icon with a plus sign).

4
Confirm & Launch

Confirm the title "FocusScroll" and tap Add in the top right. The app will appear on your Home Screen with a custom dark icon, launching in true fullscreen with no browser address bars!

🤖 Android Phone (Google Chrome)

1
Open in Chrome

Visit your hosted URL in Google Chrome on your Android device.

2
Tap "Install" or 3-Dots Menu

Chrome will usually show an "Add FocusScroll to Home screen" banner at the bottom. If not, tap the 3 vertical dots at top-right.

3
Select "Install App"

Tap "Install app" (or "Add to Home screen").

4
Native App Drawer Integration

Android adds the app to your Home Screen and your Android App Drawer just like an APK from the Google Play Store!

PART 4

100% Data Safety: Never Lose Your Lists

How to ensure your lists are completely safe forever even if you drop your phone in water.

✓ Persistent Memory

IndexedDB writes synchronously to persistent storage in your phone's flash memory. When you add or delete a video, it is committed immediately.

✓ 1-Tap "Export JSON"

Inside the drawer, tap Export JSON anytime. It downloads a clean backup file to your Files / iCloud / Google Drive.

✓ Instant "Import JSON"

Got a new phone or switching devices? Open FocusScroll on the new device, tap Import JSON, choose Replace or Merge, and all your lists and videos restore instantly.
